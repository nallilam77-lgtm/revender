# LevelUp Recargas

Panel para revendedores de recargas de **Free Fire**: recargas individuales y masivas, billetera con USDT, lista de precios, clientes, niveles con descuentos, API y soporte.

## Estado
Prototipo de interfaz. Los datos son simulados y se guardan en el navegador (`localStorage`).

## Estructura
| Archivo | Contenido |
|---|---|
| `index.html` | Estructura (login + panel) |
| `styles.css` | Diseño |
| `app.js` | Lógica, vistas y datos de ejemplo |

## Ejecutar en local
Abre `index.html` en el navegador. Usuario de demostración: `demo@levelup.store` / `demo1234`.
